## 🚀 How to Add a New Daily Entry

You can use the built-in script from the repository root:

```bash
# Using Python
python scripts/daily_log.py --topic "Your Topic" --summary "What you learned/built today"

# Or on Windows PowerShell (logs, commits, and pushes automatically)
.\scripts\daily_commit.ps1 -Topic "Your Topic" -Summary "What you learned/built today"
```
